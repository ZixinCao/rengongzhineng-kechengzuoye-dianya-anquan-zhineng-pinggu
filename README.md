# 基于神经网络的电压安全评估

人工智能课程作业提交材料。采用多层感知机，根据 80 个拓扑特征和 5 个故障位置特征，预测母线节点的暂态电压最大偏移量。

## 模型与验证

按完整输入分组后划分训练集和验证集，避免相同输入跨集。训练集 14,159 条，验证集 3,537 条；最终网络为 `85 → 64 → 32 → 1`，采用第 674 轮快照。

| 验证指标 | 数值 |
| --- | ---: |
| MAE | 0.007765157 |
| RMSE | 0.020312266 |
| R² | 0.990034404 |

验证集参与模型和训练轮次选择，以上并非独立测试成绩。训练和验证集共享拓扑类型，不能据此推断未见拓扑上的效果。

## 运行

使用 Python 3.12，在 `代码` 目录执行：

```sh
python -m pip install -r requirements.txt
python train_voltage.py --data-dir "原始数据目录"
python predict.py --input "Test_data_unlabeled.csv的实际路径"
```

原始训练数据和无标签测试输入不在本仓库内，运行时需另行指定路径。训练 CSV 无表头、86 列，最后一列为标签；预测 CSV 无表头、85 列。仅使用已保存模型进行预测时，无需重新训练。
